# 管理端功能设计

## 部署前提

平台按学校私有化部署，不依赖云服务器。  
每个学校独立运行一套系统，数据保存在本校服务器或机房电脑中。  
学校可定期导出数据采集包，交给项目方统一接收、校验、汇总和分析。
本校灾备仍可单独做备份导出，但跨校分析入口不叫“备份导入”。

因此管理端需要区分两类管理员：

- 超级管理员：项目方或部署维护人员使用。
- 学校管理员：交给学校日常使用。

教师和学生仍是教学使用角色。

## 角色模型

### 1. 超级管理员

超级管理员不是学校日常使用账号。它用于部署、维护、跨校数据处理和最高权限操作。

适用场景：

- 初始化学校系统。
- 创建学校管理员账号。
- 处理数据库备份和恢复。
- 接收多个学校的数据采集包。
- 做跨学校统一分析。
- 查看系统健康状态。
- 处理严重故障。
- 重置学校管理员密码。
- 停用学校管理员账号。
- 删除已停用的学校管理员账号。

超级管理员权限：

- 管理学校信息。
- 管理学校管理员账号。
- 管理系统级配置。
- 管理备份、恢复和跨校数据采集。
- 接收学校数据采集包。
- 查看跨校汇总数据。
- 查看所有日志。
- 管理模型训练任务和版本。
- 管理全局模板和公共标准。

建议：

- 学校日常不使用超级管理员账号。
- 超级管理员账号由项目方保管。
- 每个学校本地系统至少保留一个超级管理员账号用于维护。
- 学校只拿学校管理员账号和密码。

账号删除规则：

- 所有账号都必须先停用后删除，包括学校管理员、教师和学生。
- 启用状态账号不能直接删除。
- 超级管理员的学校管理、学校管理员管理支持当前页多选和全选。
- 学校、学校管理员、教师、学生、班级使用统一的批量停用/删除交互。
- 批量删除如果选中启用项，系统先执行批量停用，用户重新勾选后再删除。
- 删除确认页必须有明确二次提示。
- 删除动作必须写操作日志。
- 若账号已有课程、资源、学习行为、评价记录等业务关联，系统应阻止物理删除并保留停用状态。

### 2. 学校管理员

学校管理员负责本校平台日常管理。

权限：

- 管理本校教师、学生。
- 管理本校班级、年级、学期。
- 管理任课关系。
- 管理教师权限。
- 管理本校公共题库。
- 管理评价模板。
- 查看本校模型训练任务。
- 查看本校操作日志。
- 导出本校备份包。

不能做：

- 查看其他学校数据。
- 接收其他学校数据采集包。
- 做跨校分析。
- 修改超级管理员账号。
- 修改系统底层部署配置。

### 3. 教师

教师负责教学内容和本班教学过程。

权限：

- 管理自己的课程、课时、资源、活动、测试、项目任务。
- 管理个人题库。
- 引用本校公共题库。
- 发布前测、测试、问卷、项目评价。
- 查看本班学习档案和分层建议。
- 确认或驳回本班分层建议。

教师额外权限由学校管理员配置：

- 是否允许批量导入题目。
- 是否允许提交题目到公共题库。
- 是否允许审核公共题目。
- 是否允许导出学生数据。
- 是否允许查看学习行为明细。
- 是否允许手动调整学生层级。
- 是否允许使用课堂实时功能。

### 4. 学生

学生只使用学习功能：

- 课程学习。
- 资源查看。
- 签到。
- 答题。
- 测试。
- 项目提交。
- 自评互评。
- 查看个人学习档案。

## 题库归属

题库分为公共题库和教师个人题库。

### 公共题库

由学校管理员管理。

功能：

- 公共题库目录。
- 题型、知识点、难度、标签。
- 公共题导入。
- 公共题审核。
- 公共题停用。
- 导入模板。
- 导入校验记录。
- 题目使用记录。

### 教师个人题库

由教师管理。

功能：

- 新增、编辑、删除自己的题目。
- 批量导入自己的题目。
- 个人题库分类。
- 在前测、测试、活动中使用。
- 从公共题库引用题目。
- 复制公共题到个人题库后修改。

### 题库权限

由学校管理员配置给教师：

- 创建个人题库。
- 批量导入题目。
- 引用公共题库。
- 提交题目到公共题库。
- 审核公共题目。
- 导出题目。
- 删除已使用题目。

## 模型与训练归属

模型和训练属于管理端，但教学采用权属于教师。

### 超级管理员

- 管理全局模型配置。
- 查看跨校模型训练情况。
- 接收多个学校数据采集包后做统一分析。
- 对不同学校的数据做汇总报告。
- 管理模型代码、模型版本和训练策略。

### 学校管理员

- 查看本校班级模型。
- 查看本校训练任务。
- 手动触发本校训练任务。
- 查看训练失败原因。
- 启用、停用、回滚本校模型版本。
- 导出本校模型运行报告。

### 教师

- 查看本班分层建议。
- 查看建议原因。
- 确认或驳回建议。
- 对学生层级做教学调整。

默认规则：

- 模型不直接修改学生层级。
- 分层建议需教师确认。
- 自动生效暂不做。
- 模型版本切换写入日志。

## 离线数据采集与跨校汇总

### 学校端数据采集包

学校管理员可以导出本校数据采集包，供项目方跨校分析使用。
这个包不是系统恢复包，默认不用于还原生产系统。

数据采集包建议包含：

- 学校信息。
- 学年学期。
- 班级。
- 教师。
- 学生。
- 课程。
- 课时。
- 资源元数据。
- 测试和题库。
- 学习行为事件。
- 学习档案。
- 分层建议记录。
- 模型训练记录。
- 操作日志摘要。

数据采集包不建议默认包含：

- 明文密码。
- 原始密钥。
- 临时缓存。
- 无关日志。

导出要求：

- 压缩包带学校编号。
- 压缩包带采集时间。
- 生成校验文件。
- 记录导出人、采集范围和数据窗口。
- 可选脱敏。

### 项目方接收采集

超级管理员在项目方分析环境中接收学校数据采集包。

功能：

- 解压数据采集包。
- 校验学校编号、采集时间、版本号。
- 检查数据结构版本。
- 写入或更新汇总数据库。
- 标记来源学校。
- 避免不同学校数据 ID 冲突。
- 生成采集报告。
- 生成跨校统计和模型分析数据。

### 数据隔离

跨校分析时必须保留学校维度：

- school_code
- collection_batch_id
- source_system_version
- collected_at

不同学校的数据不能混写成同一个班级或同一个学生。

## 学校管理员功能

### 1. 管理首页

只显示本校平台运行和待处理事项。

内容：

- 教师、学生、班级、课程数量。
- 当前学年学期。
- 账号异常。
- 导入任务状态。
- 服务状态。
- 存储空间。
- 最近备份时间。
- 待处理题库审核。
- 失败训练任务。

### 2. 用户管理

功能：

- 教师账号。
- 学生账号。
- 新增、编辑、停用、启用。
- 删除已停用账号。
- 批量导入、导出。
- 重置密码。
- 首次登录强制改密。
- 查看最近登录时间。

### 3. 教师权限

功能：

- 按教师配置权限。
- 批量配置权限。
- 权限模板。
- 权限变更日志。

权限项：

- 课程创建。
- 资源上传。
- 题库导入。
- 公共题提交。
- 公共题审核。
- 测试发布。
- 项目发布。
- 学生数据导出。
- 学习行为明细查看。
- 分层建议查看。
- 分层建议采用。
- 手动调整分层。
- 实时问答。
- 课堂控制。

### 4. 班级管理

功能：

- 年级。
- 班级。
- 学生转班。
- 学生升班。
- 毕业归档。
- 班级启用、停用。

### 5. 任课关系

功能：

- 教师绑定班级。
- 教师绑定课程。
- 一个班多个教师。
- 一个教师多个班。
- 批量导入任课关系。

### 6. 题库中心

功能：

- 公共题库管理。
- 题型管理。
- 知识点管理。
- 难度等级。
- 题目标签。
- 导入模板。
- 导入校验。
- 公共题审核。
- 题目使用记录。

### 7. 评价模板

功能：

- 前测模板。
- 问卷模板。
- 评价标准模板。
- 自评模板。
- 互评模板。
- 师评模板。
- 评价维度与权重。

学校管理员维护模板，教师发布到班级。

### 8. 模型与训练

功能：

- 本校班级模型列表。
- 训练任务。
- 训练时间。
- 训练失败日志。
- 模型版本。
- 模型回滚。
- 分层建议生成记录。
- 教师采纳率。
- 数据不足提示。

### 9. 备份导出

功能：

- 手动导出备份包。
- 查看历史导出。
- 校验文件。
- 导出范围选择。
- 脱敏选项。
- 导出日志。

### 10. 系统设置

功能：

- 平台名称。
- 本地 Logo、favicon。
- 首页文字。
- 学年学期默认值。
- 密码策略。
- 上传类型和大小。
- 存储目录状态。
- WebSocket 地址。
- 离线依赖版本。

### 11. 操作日志

功能：

- 登录日志。
- 用户变更日志。
- 权限变更日志。
- 导入导出日志。
- 题库审核日志。
- 模型任务日志。
- 备份日志。

## 暂不做功能开关

功能开关第一阶段先不做。  
需要控制的能力先通过“教师权限”和“系统设置”解决。  
后续如果学校差异明显，再单独增加功能开关模块。

## 第一阶段实现顺序

已完成：

1. Vue 登录页。
2. 超级管理员数据总览。
3. 超级管理员学校管理：列表、查询、筛选、新增、编辑、停用、归档、删除。
4. 超级管理员学校管理员管理：列表、查询、筛选、新增、编辑、启用、停用、删除、重置密码。
5. 学校管理员管理首页。
6. 学校管理员教师管理：列表、查询、筛选、新增、编辑、启用、停用、删除、重置密码。
7. 学校管理员学生管理：列表、查询、筛选、新增、编辑、启用、停用、删除、重置密码。
8. 学校管理员班级管理：列表、查询、筛选、新增、编辑、停用、归档、删除。
9. 超级管理员学校管理和学校管理员管理的多选、全选、批量停用、批量删除。
10. 学校管理员任课关系：按教师聚合展示，弹窗批量设置任教班级。
11. 学校管理员学科与学科前测：学科、学科前测套卷、题目基础维护。
12. 通用后台组件：管理列表、表单弹窗、确认弹窗、状态徽标、指标卡、批量操作条。

下一步：

1. 教师权限。
2. 学科前测批量导入、模板下载和导出。
3. 学生首次使用前测作答页。
4. 题库中心。

6. 模型与训练。
7. 数据导出。
8. 操作日志。
