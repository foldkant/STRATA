## 0. 核查方法与证据边界

本文件中的“五轮科学验证”是对设计假设的五轮文献核查和反证审查，不是对 STRATA 教学效果的实证验证，也不是 PRISMA 系统综述。2026-07-20 使用 OpenAlex 补充发现 2020-2026 年文献，并通过 Crossref 逐条核验本文件引用的 DOI、题名、期刊和出版年份；检索式、候选状态和来源限制保存在补充检索记录中。

证据按用途分开：

- 教育测量和个性化测验文献用于限定“不同任务能否比较”以及测量误差如何进入决策。
- K-12 分组、个性化学习和学习分析研究用于识别课堂实施、公平与学生权益风险。
- 知识追踪和机器学习论文只证明某些估计方法可比较，不证明动态分层能够提高学习效果。
- 随机试验和多层因果方法文献用于设计后续实证，不作为当前平台有效性的证据。
- 只完成元数据核验、尚未完成全文双人复核的新文献不引用具体效应量、样本量或显著性结论。

因此，本轮能形成的是**可证伪的设计约束和实证路线**。只有完成前瞻性影子验证与集群随机教学研究后，才能讨论预测有效性和教学效果。

## 1. 最终判断

动态分层可以成为科学、可检验的教学支持机制，但必须满足以下条件：

1. A/B/C 是按学科、课程和时间有效的内部内容投放带，不是学生能力身份。
2. 内容难度依据可比较的掌握证据；完成、逾期和资源使用只决定支持需要，不能直接决定降层。
3. 分层任务用于教学，共同锚题和可链接表现任务用于跨层比较。
4. 夜间更新数据不等于夜间变层；内容带只在预先登记的周度或单元决策点变化。
5. 预测模型只回答“当前教学政策继续时可能发生什么”；动态分层是否有效必须通过前瞻性试验验证。
6. 教师确认、学生隐性、升级机会、停止规则和完整审计是模型的一部分，不是界面附加功能。

当前测试实现尚未达到这个目标。现有模拟模型主要预测未来 7 日逾期或完成情况，并按预测值的班内三分位生成 A/B/C。这只能作为完成支持模型的工程验收，不能作为正式内容层级。

## 2. 当前实现与目标模型的差距

| 项目 | 当前工程实现 | 科学目标 |
| --- | --- | --- |
| 主要结果 | 随后 7 日完成率、新增逾期数 | 下一次计划共同测量掌握、成长、完成和逾期分别建模 |
| A/B/C 映射 | 预测值班内三分位 | 课程标准参照阈值和测量不确定性 |
| 完成与掌握 | 在最终 A/B/C 中仍可能混合 | 两条独立轴，在教学策略层组合 |
| 层级数据 | `StudentProfile.current_layer` 全局缓存 | 学生 × 学科/课程 × 有效期的版本记录 |
| 变层规则 | 教师处理单条候选 | 连续证据、滞回、冷却期、单次一级、教师确认 |
| 训练频率 | 可夜间产生候选 | 夜间汇总和推理；成熟结果到达后才训练或重校准 |
| 有效性证据 | 模拟数据流程和指标 | 前瞻性预测验证、外部验证和集群随机教学效果研究 |

必须保留现有完成/逾期模型，但将其定位为“完成支持预测”，停止用单一结果直接生成内容难度。

## 3. 第一轮：测量可比性

### 3.1 被否决的方案

- 比较 A 层高难任务与 C 层基础任务的原始分数或完成率。
- 用班级排名或三分位强制产生固定比例 A/B/C。
- 把教师自行生成、尚未校准的题目直接用作升降层依据。

这些做法混合了学生状态、题目难度、任务负荷、支架和教师评分，无法说明学生是否具备进入下一内容带的准备度。

### 3.2 采用的测量结构

每个单元至少包含：

1. `共同核心任务`：所有学生获得相同核心目标和基本学习机会。
2. `共同锚题`：低负担、跨内容带保持可比，用于掌握估计和版本链接。
3. `A/B 与 B/C 衔接题`：给边界学生提供向上或向下的局部测量信息。
4. `分层教学任务`：用于支架、练习和挑战，不默认承担跨层测量功能。
5. `共同表现任务`：复杂作品使用经验证且可链接的评价标准，保留任务和评分者误差。

共同锚题必须记录题目版本、知识点、难度、曝光、位置、DIF、漂移和答案泄露状态。IRT 样本不足时先使用固定共同测量及标准参照得分，不为使用 IRT 而强行估计不稳定参数。

本轮主要依据教育测量与个性化测验效度框架 [D1-D2]。它们支持把测量误差、任务适配和可比性作为解释个性化结果的前置条件，但不为 STRATA 的具体阈值背书。

### 3.3 可检验结果

- 锚题在内容带、班级、学校和时间上的参数稳定性。
- 共同测量的可靠性、条件标准误和分类一致性。
- DIF、题目漂移和不同层级的测量机会覆盖。
- A/B、B/C 衔接题是否降低边界学生的不确定性。

## 4. 第二轮：动态迁移规则

### 4.1 被否决的方案

- 每晚根据最新完成率自动改层。
- 单次测试或一次课堂失败后立即降层。
- 用当前班级均值中心化后解释绝对准备度。
- 把夜间滚动快照都当成相互独立的研究样本。

### 4.2 两种更新速度

- `支持信号`：每天更新。包括逾期风险、完成困难、资源未使用和需要教师核查的访问问题。
- `内容投放带`：只在预先登记的周度或单元决策点更新。课堂中可以临时投放支架，但不改正式层级历史。

### 4.3 掌握状态与边界带

每个决策点生成掌握估计 `M`、不确定区间以及两个由课程标准审定的阈值：

- `tau_core`：进入核心发展内容所需的最低掌握标准。
- `tau_extension`：进入拓展挑战内容所需的准备度标准。

策略层使用概率或区间，而不是只看点估计：

- 充分证据支持 `M >= tau_extension`：A 候选。
- 充分证据支持 `M < tau_core`：C 候选。
- 其余稳定范围：B 候选。
- 区间跨越相邻阈值：A/B 或 B/C 边界，不强制单层。
- 测量不足、域外或数据异常：`abstain`，保持原安排并补充证据。

阈值和“充分证据”的概率门槛必须在外部测试前冻结；不得根据哪组模型指标更漂亮事后选择。

### 4.4 迁移保护

1. 升级和降级使用不同的进入/退出门槛，形成滞回区间。
2. 正式变层原则上需要连续两个计划决策点支持；紧急教学处置单独记录，不改长期带。
3. 每次最多移动一级。
4. 变层后至少冷却一个教学周期。
5. 完成风险升高不直接降内容带。
6. 当前层任务过少、设备不可用、请假或缺少共同测量时不变层。
7. 教师可接受、保持、调整或暂缓，并保存独立理由。

知识追踪综述说明掌握状态可以随作答序列更新 [D3]，但并未证明“模型每更新一次，教学内容带就应变化一次”。因此平台把状态估计频率与教学决策频率分开，并将滞回、冷却期和拒绝建议作为预先登记的策略规则，而不是从文献中虚构一个通用最佳数值。

## 5. 第三轮：预测与教学效果

### 5.1 被否决的方案

- 用高 AUC、R2 或教师接受率证明动态分层有效。
- 在模型已经影响学生任务后，把后续表现当成自然能力标签。
- 从教师历史选择直接训练“最佳内容带”或使用在线强化学习自动调整。

分层改变学生获得的题目、支架和教师注意，后续结果是学生状态与教学处理共同产生的。观察性预测不能识别“如果换一种内容带会怎样”。

### 5.2 证据阶段

#### 阶段 P0：测量与流程试点

- 完成共同题内容审核、认知访谈、评分者培训、锚题链接和数据完整性检查。
- 不训练正式策略，不比较教学效果。

#### 阶段 P1：前瞻性影子验证

- 至少覆盖一个完整学期和多个预先登记决策点。
- 模型生成隐藏预测，但教师和教学安排不受影响。
- 主要验证未来掌握、完成和逾期的时间外、班级外和学校外性能。
- 该阶段只能声称预测和校准表现，不能声称提高学习。

#### 阶段 P2：集群随机教学效果研究

首项效果研究优先采用班级或教师为集群的随机对照设计：

- `干预组`：教师看到相同学习证据和动态内容带/支持建议，可以接受、修改或拒绝。
- `主动对照组`：教师看到相同学习证据，但不显示算法内容带建议，继续由教师判断。

这样可以区分“仅有数据看板”的作用与“动态建议”的增量作用。若同一教师同时教授两组容易发生污染，应按教师或教师所教全部班级随机；学校必须分阶段上线时才考虑阶梯式集群设计，并显式控制时间趋势。

#### 阶段 P3：序贯支持策略研究

只有 P2 证明安全和平均效果后，才考虑 SMART 或微随机研究比较提醒、示例、教师介入等支持序列。首期不使用强化学习自动选择内容难度。

自适应学习元分析只能说明该类系统总体上值得进一步研究，不能替代对 STRATA 具体机制的因果验证 [D4]。教育随机试验的方法证据支持按班级或教师处理嵌套与污染 [D5]；模型的 RMSE、R2 或 AUC 与教学干预效果属于两个不同研究问题。

## 6. 第四轮：公平、教师协同与学生权益

### 6.1 被否决的方案

- 认为学生看不到 A/B/C 就已经消除分组伤害。
- 只删除性别等字段就宣称公平。
- 以教师采纳模型作为模型正确性的金标准。

即使标签隐性，如果某些学生长期只获得低难任务、较少挑战和较低教师期待，仍可能产生机会差异和自我实现效应。

### 6.2 必须监测的完整链路

- 测量：共同题覆盖、DIF、测量误差和评分差异。
- 机会：不同内容带获得的核心任务、挑战题、支架和教师反馈。
- 预测：各群体校准、误差、拒绝率和不确定性。
- 建议：升级、降级、保持和无建议的覆盖差异。
- 人工处理：教师接受、修改、拒绝和处理时间差异。
- 后果：掌握增长、完成、学生自主性、信心、负担和不良影响。

### 6.3 产品约束

- 学生端不显示层级、排名、概率或能力型组名。
- 学生仍能看到共同目标、任务要求、评价标准和获得的支持，并可申请教师复核。
- 教师审核页显示证据时间窗、共同测量版本、不确定性、反证和缺失原因。
- 教师投屏默认隐藏学生姓名与内部层级对应关系。
- 层级不能自动决定协作分组；同层、异层和随机分组按具体任务另行比较。

动态分组的任务策略、稳定保护、约束优化和实证比较见[学生动态分组十轮科学核查](dynamic_grouping_ten_round_validation.md)。

中学分组纵向研究提示固定成就分组可能关联自信累积和机会差异 [D6-D7]；个性化学习、公平和人本学习分析研究进一步要求检查学生获得的任务、支架及教师处理，而不只是检查算法输入是否包含敏感字段 [D8-D9]。这些研究支持保守治理，但不能直接给出本平台的因果效应大小。

## 7. 第五轮：外部验证与长期运行

### 7.1 模型路线

先比较透明规则、正则化统计模型、多层模型、CatBoost 和 LightGBM。算法名称不预先决定胜者，模型必须在相同数据折、相同特征集和相同未来结果上比较。

“一班一模型”采用：

```text
学校/学科全局模型
  + 班级基线和机会结构
  + 小样本收缩校准
  + 课程标准参照阈值
  + 迁移和停止规则
  = 班级专属模型包
```

单班 40-60 人不从零训练复杂树模型。班级数据不足时只更新稳健校准参数；仍不足则回退到学校/学科模型或拒绝建议。

### 7.2 验证顺序

1. 同一学生分组的内部开发验证。
2. 后续时间段验证。
3. 未参与训练的班级/教师验证。
4. 未参与训练的学校验证。
5. 新学期、新课程版本和题库改版后的再验证。

每一层都报告样本和机会覆盖、MAE/RMSE、R2、校准截距/斜率、预测区间覆盖、拒绝率、班级差异和公平审查。分类结局另报告 Brier、灵敏度、特异度和适合实际教师容量的决策效用；不能只报告准确率或 AUC。

### 7.3 漂移与停止

- 共同题失去链接、出现 DIF/泄露或参数漂移。
- 数据含义、课程目标、任务负荷或教师流程发生不兼容变化。
- 时间外或学校外校准明显失效。
- 建议频繁反转、教师无法处理或某些群体持续缺少升级机会。
- 动态建议不优于透明规则，或产生可确认的不良后果。

任一红线触发暂停新建议、隐藏旧预测并回退教师人工模式，而不是继续夜间更新。

K-12 学习分析综述、跨教学条件的学习预测研究和机器学习研究报告规范共同支持时间外、班级外、学校外验证以及持续监测 [D10-D12]。其中通用机器学习规范只用于研究质量控制，不直接外推教育效果。

## 8. 最终动态分层结构

### 8.1 四类独立输出

| 输出 | 依据 | 用途 | 是否直接决定 A/B/C |
| --- | --- | --- | --- |
| 掌握与挑战准备度 | 共同锚测、可链接表现任务、知识点轨迹 | 内容难度 | 是，经过策略规则 |
| 完成支持信号 | 未来完成与逾期的独立预测 | 提醒、计划和教师跟进 | 否 |
| 成长趋势 | 可比掌握测量的纵向变化 | 判断上升/停滞和补充证据 | 辅助，不单独决定 |
| 访问与数据状态 | 请假、设备、离线、机会不足和异常记录 | 拒绝预测、补充机会 | 否，不能作为降层证据 |

### 8.2 典型组合

| 掌握准备度 | 完成支持需要 | 内容与支持安排 |
| --- | --- | --- |
| 高 | 低 | A 内容，正常支持 |
| 高 | 高 | 保持 A 内容，增加计划、提醒和核查，不降 C |
| 中 | 任意 | B 内容，根据完成预测增加支持 |
| 低 | 低 | C/B 衔接内容，重点提供概念支架 |
| 低 | 高 | C 内容，同时提供概念支架和完成支持 |

### 8.3 夜间任务边界

每天夜间可以：

- 汇总事件、更新学习数据检查和特征快照。
- 更新完成/逾期支持风险。
- 在到达登记决策点时生成内容带候选。
- 训练数据达到成熟条件时生成新的影子模型候选。

每天夜间不可以：

- 因当天点击、完成率或一次低分自动变层。
- 在没有新成熟未来结果时反复重训并发布模型。
- 自动改变学生正式内容带。

## 9. 实证分析方案

### 9.1 主要研究问题

1. 动态建议相较于相同数据看板下的教师判断，是否改善下一周期共同测量掌握结果。
2. 是否改善完成与逾期，而不降低挑战机会或学生自主性。
3. 效果是否在学校、班级、既往掌握和合法审计群体间稳定。
4. 教师是否能在真实时间预算内理解、处理和纠正建议。

### 9.2 主要与次要结果

- 主要结果：单元末共同锚测掌握结果，使用基线调整后的连续估计或经审定的标准分。
- 关键次要结果：经验证共同表现任务、未来完成分子/分母、新增逾期数。
- 实施结果：建议查看、接受、修改、拒绝、实际投放、学生使用和教师处理时间。
- 安全与公平结果：共同核心和挑战机会、层级停留/反转、群体覆盖、学生自主性和教师负担。
- 禁止作为主要效果结果：A/B/C 人数、教师接受率、课堂积分和模型训练集性能。

### 9.3 主要统计分析

- 主分析采用意向治疗原则，按原随机组分析。
- 主要掌握结果采用多层 ANCOVA 或相应广义混合模型，调整基线掌握和预注册协变量。
- 至少考虑学生重复测量、班级和学校嵌套；随机结构由设计和样本支持决定，不机械堆叠。
- 报告组间效应、95% 置信区间和绝对差异，不只报告显著性。
- 实际采用动态建议的分析作为次要实施分析，不能替代意向治疗结果。
- 多个次要结果按预注册层级或错误率控制解释，探索结果明确标记。

### 9.4 缺失、污染和干扰

- 请假、转学、任务撤回、设备不可用和未获得机会分别保存，不能统一为 0。
- 对主要结果说明缺失机制，执行完整案例、多重插补和预注册敏感性分析。
- 保存对照组接触动态建议、干预组未采用建议等污染事实。
- 同班学生共享教师和同伴，不能把学生当作完全独立；共同小组作品不复制为多条个人结局。

### 9.5 样本量

不提前写死“多少学生即可”。先用 P0/P1 获得：

- 班级内相关系数和学校间差异。
- 基线与后测相关、结果标准差和测量误差。
- 班级数、平均班额、流失和污染率。
- 具有教学意义的最小效果。

随后使用集群和重复测量结构进行模拟功效分析。只有学生人数多、班级数少仍可能没有足够统计功效。

### 9.6 预注册与复现

研究开始前冻结：

- 研究问题、主要结果、阈值、决策点、特征和模型版本。
- 随机单位、分配方法、排除、缺失、污染和统计模型。
- 亚组、公平、停止和多重比较规则。
- 数据锁、代码版本、模型包签名和分析运行编号。

任何事后调整形成新版本并作为探索分析，不能覆盖原预注册结果。

- “完成率低说明学生应进入 C 层。”
- “教师采纳证明模型正确。”
- “模拟数据结果证明动态分层提高成绩。”
- “每个班独立训练的 AI 模型已经有效。”
