# 伦理与隐私检查表

## 原则

平台处理未成年人学习数据，默认采用最小采集、校内处理、按角色访问、教师最终确认和学生隐性分层。模拟数据只能验证程序，不能替代真实伦理审批或研究证据。

## 启动前

- [ ] 伦理委员会/学校审批编号、版本和有效期已登记。
- [ ] 明确研究、教学运行和系统运维三个处理目的，不混用授权。
- [ ] 未成年人同意、监护人同意和退出流程符合所在地要求。
- [ ] 告知采集类别、用途、保存期限、访问角色、可能风险和申诉渠道。
- [ ] 学生不因拒绝研究使用而失去正常课程学习机会。
- [ ] 外部 AI 不接收学生身份、原始答卷、聊天、学习档案或内部层级。

## 数据分级

| 级别 | 示例 | 默认访问 |
| --- | --- | --- |
| 直接身份 | 姓名、账号、学号、班级 | 本校授权人员 |
| 教学记录 | 答卷、作品、评价、聊天、签到 | 任课教师及必要管理员 |
| 分析数据 | 匿名编号、冻结指标、未来结果 | 受控分析人员 |
| 模型与审计 | 模型包、签名、模型卡、发布记录 | 学校管理员和研究负责人 |

跨校汇总只接收去直接身份的数据包。学校代码、班级规模和小群体组合仍可能造成再识别，导出前必须执行小单元检查和访问审批。

## 权利与人工监督

- 学生和监护人可查询平台保存的数据类别、申请更正身份匹配错误并按审批流程撤回研究使用。
- 学生不看到隐性层级、置信度、排名或内部解释，但可得到实际学习任务和教师反馈。
- 教师确认所有分层建议；平台不得自动分班、自动降级或自动处分。
- 不良言论、扣分和课堂评价均保留人工处理及审计。

## 安全检查

- [ ] 生产环境关闭 `DEBUG`，使用 HTTPS、安全 Cookie 和独立随机密钥。
- [ ] PostgreSQL、Redis 和文件目录不向学生网络开放管理端口。
- [ ] 模型签名私钥、隔离区密钥、数据库密码和教师 API Key 不进入 Git 或跨校包。
- [ ] 备份加密并完成恢复演练。
- [ ] 学生 API、WebSocket、下载文件名和浏览器缓存通过隐性字段阻断测试。
- [ ] 安全事件有报告、隔离、通知、恢复和复盘流程。

## 公平性与跨校验证边界

公平性、稳定性和跨校有效性只能在获得真实纵向数据并满足预注册样本条件后执行。小群体不输出不稳定指标；报告群体差异时同时给出样本量、不确定性和数据缺失，不把无差异解释为公平。

## 数据可用性工作稿

学生级原始数据包含受保护的未成年人教育记录，默认不公开。论文所需的去标识汇总数据、变量字典、分析代码和模拟示例数据可在伦理审批和学校协议允许的范围内公开；受控学生级数据的申请条件、审批主体、保存期限和访问方式必须在正式投稿前填写，不使用模糊的“可向作者索取”。
