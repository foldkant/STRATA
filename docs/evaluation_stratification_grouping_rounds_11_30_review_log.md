# 评价、动态分层与动态分组第 11—30 轮独立审稿式复核记录

> 日期：2026-07-22  
> 对象：`evaluation_stratification_grouping_sci_design_rounds_11_30.md`  
> 性质：三个并行 AI 审稿角色分别从评价效度、统计/因果、代码与数据治理角度进行对抗性复核；不是外部人类同行评审、伦理批准或已完成实验。  
> 目标：保留设计变更理由，避免后续开发或写作重新引入已识别错误。

## 1. 复核轨道

| 轨道 | 核心审查问题 | 重点证据 |
| --- | --- | --- |
| 评价与测量 | 主张是否可证伪；内容、反应过程、结构、概化、评分和用途是否混淆 | 第 11—16 轮、评价蓝图与评分准入 |
| 统计、预测与因果 | estimand、切分、泄漏、缺失、校准、干扰、功效和外部验证是否成立 | 第 17—30 轮与 SCI 研究计划 |
| 代码与治理 | 当前类/字段、真实记录、已运行行为和拟议能力是否被混写 | 当前实现表、AS-IS/TO-BE 和数据对象迁移 |

| R20 | IRT、BKT、状态空间模型不是只按预测表现比较的同类模型 | 接受：按构念、观察结构、知识组件和识别条件选择 | 第 17 轮、6.4 |

| R22 | 缺失机制类型和 MI/IPW/AIPW 不能作为通用菜单 | 接受：按协变量缺失、失访、结构性不适用、无机会和选择性评分分别定义 | 第 19 轮、10.4 |

| R27 | 普通学生级分析无法处理同伴干扰 | 接受：主目标为班级/教师集群政策 ITT；个体同伴效应需专门两阶段随机化/识别设计 | 第 25 轮、10.5 |
| R28 | 动态不等于频繁；稳定组也可能固化排斥 | 接受：阶段冻结 + 安全退出/求助/复核；紧急变更仍保留在 ITT 并作安全结果 | 第 26 轮、7.4 |

| R32 | 集群、阶梯楔形、SMART 和 MRT 不可互换 | 接受：首项政策效果优先平行集群 RCT；其他设计只在匹配决策问题时采用 | 第 30 轮 |
| R33 | 当前代码对象、已有记录、已验证能力被混写 | 接受：当前评价记录稀少；逐对象标“现有调用/占位/拟扩展/拟新增/研究变量” | 3、8.1 |

| R35 | 新证据/结果/机会类可能与现有事实源重叠 | 接受：优先扩展 `LearningEventV2`、`AssessmentResultFact`、`EvaluationSubmissionEvidence`、`LearningOpportunity*`、`OutcomeDefinition/Observation` | 8.1—8.2 |
| R36 | 假名化被误写成匿名化，版本保留不能覆盖法定删除 | 接受：密钥隔离、到期删除/不可逆匿名化、撤回和非个人审计摘要 | 8.2、10.6 |
| R37 | 商业 AI 同名版本不可保证重放 | 接受：保存供应商、快照、日期/区域、参数、提示、知识库哈希、原始响应、重试与人工差异 | 5.3、14 |
| R38 | 未成年人伦理与开放科学不足 | 接受：新增退出不受罚、申诉、安全结局、暂停责任人、Registered Report 和复现包 | 10.6、13—14 |

## 3. 有意保留为“待决策/待数据”的事项

以下内容没有在文档中伪造答案：

- 第一试点的学段、学科、年级、单元和任务类型；
- 随机化究竟按班级、教师还是学校；
- 一个主要教育结局和一个主要机会/安全结局；
- 各指标的单位化最小重要差异、非劣界值和停止阈值；
- ICC、任务/评分者方差、失访、拒绝和污染等样本量参数；
- 公平审计群体、合法依据和最小可报告精度；
- 伦理审批、同意/学生同意方案和外部独立学校；
- 现有 JSON 到项目/成员/角色版本表的具体双写与切换批次。

这些事项必须由项目负责人、学科/评价专家、学校、伦理/隐私角色与统计人员在查看确认性结果前共同冻结。

## 4. 复核结论

复核后的报告达到“可用于产品底层决策和后续协议开发”的状态，但尚未达到“可以直接招募、随机和发表结果”的状态。下一道科学门不是再写一轮肯定性论证，而是由用户选择一个小作用域，把估计目标注册表的一行补成完整、经伦理审查和仿真功效支持的预注册协议。
