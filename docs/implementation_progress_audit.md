# STRATA 当前开发进度

> 核对日期：2026-07-20  
> 核对依据：Git 提交、数据库迁移、自动化测试、Vue 构建和本机组件运行结果。

## 1. 总体结论

平台主要教学业务已经可以运行。学生学习记录、学校管理员学习数据检查、正式评价标准闭环、题目完整状态、共同题比较、基础学习情况汇总、教师审核建议、版本化学习指标、计划分析时间点、未来结果、冻结数据版本、重复测量统计、透明基线、CatBoost/LightGBM 同折比较和班级校准候选已经完成工程闭环。下一步是正式学校试用和真实纵向数据验证。

不能把“页面已经存在”或“有模拟数据”理解为 AI 分层已经完成。目前没有可用于正式教学决策的模型结果。

## 2. 已经完成

### 平台基础

- Django、Vue 3、DRF、Channels 和 Celery 工程已经建立。
- 超级管理员、学校管理员、教师和学生主要页面已经接入 Vue。
- PostgreSQL、Redis、Channels 和 Celery 已完成本机验证。
- 学生端主要接口、WebSocket 和文件访问已经检查内部层级字段泄漏。

### 教学业务

- 学校、学校管理员、教师、学生、班级和任课关系管理。
- 学科前测、题库、测试、课程、课时设计和课堂教学。
- 资源、ONLYOFFICE、AI 学习网页、公告、反馈和学生档案。
- 签到、随机点名、抢答、倒计时、广播、小组合作、课堂评价和实名文字聊天。

### 学习记录

- 37 个受控学习事件结构版本。
- 学生实际获得的学习任务和任务状态。
- 客观题自动评分、主观题待评和教师复评版本。
- 课堂积分流水、冲正和余额核对。
- 新旧记录兼容写入、历史回填和记录核对。
- 学校管理员学习数据检查、XLSX 导出和夜间自动任务。

### 评价管理

- 评价方案和评价标准编辑。
- 评价指标、1-5 星表现说明和评分示例。
- 发布后保留不可修改的历史版本。
- 教师按本人课程维护和发布；学校管理员不进入编辑页面。
- 课时环节选择已发布评价标准，并设置自评、互评和教师评价。
- 课堂首次开启评价时冻结标准版本和完整星级说明。
- 正式评价提交关联同一学生在本课堂、本环节的最新作答和作品。
- 每个评价指标支持 1-5 星或暂不评价，暂不评价保留结构化原因且不计入平均星级。
- 教师端同时显示提交人数、已评分指标数和暂不评价指标数。

### 学习指标与数据版本

- 已登记 25 项首期学习指标及版本、用途、允许事件、最少材料量和缺失原因。
- 已建立固定分析时间点和学生范围；冻结后不可修改。
- 已区分“当时可用数据”和“事后完整数据”，训练数据只能使用前者。
- 已生成 7 日、14 日、30 日多窗口特征，保存值、分子、分母和缺失原因。
- 尚未具备采集或验证条件的研究候选指标保持“暂不可计算”，不补零。
- 已实现随后 7 日必做任务完成率和新增逾期任务数；无任务时保留“无可用结果”。
- 已实现匿名、不可变、可重复的数据版本和 XLSX 导出。
- 数据质量和教师支持字段只用于检查，不进入首期主模型输入。

### 统计验证与透明基线

- `LONG-01` 已完成工程闭环：同一冻结数据版本计算个人内变化、学生间差异、班级描述差异、重复测量相关结构和确定性范围。
- `MODEL-01` 已完成工程闭环：M00-M03 透明基线、V-A 至 V-E 验证折、每行预测的 `predicted/abstained` 状态、负对照和模型卡。
- V-D、V-E 在当前单校单测量版本数据中明确标记“暂不适用”，不制造跨校或测量变化结论。
- 模型比较默认为影子结果；没有任何接口会据此自动修改学生分层或向学生展示内部判断。
- 已接入学校管理员页面、API、XLSX 导出和每天 03:10 的夜间任务；同一数据版本重复运行返回原记录。

### 结构化模型与班级校准

- `MODEL-02 v2` 已完成：M00-M03、CatBoost 和 LightGBM 使用相同 V-A 至 V-E 范围比较。
- 已保存校准、稳定性、班级差异、特征重要性和五项防误判检查。
- 两校模拟数据的 V-D 跨校折均使用另一学校最新兼容的 576 条记录；V-E 没有第二测量版本时保持“暂不适用”。
- `MODEL-03 v3` 已完成：全局结构化模型加班级残差收缩参数，每校 4 组班级参数和 96 条教师候选。
- 旧候选保留为历史并标记被新版替代；候选不会自动修改学生当前层级。
- 教师待办已按“待处理 / 历史记录”分开并分页；历史记录为只读，不能再次提交处理。
- 班级校准候选会替代同一学生、课程的透明规则待办，避免教师同时处理两种来源；透明规则继续用于基线比较。
- 模型依据在教师端使用中文指标和百分比、分钟等单位，不显示内部特征键。

### 模拟数据

- 独立模拟学校和当前学校叠加测试两种模式。
- 固定随机种子，可重复生成同一批数据。
- 正式数据与模拟数据隔离。
- 支持整批清理。

## 3. 本次刚完成

### 候选发布、共同测试 V2 与页面验收

- 新增模型发布记录和不可修改审计，支持候选发布、当前版本替换、历史版本回滚和测试/正式版本隔离。
- 模型文件与 ZIP 均执行 SHA-256，离线包使用 Ed25519 签名；失败发布不会停用当前版本。
- 教师 MODEL-03 建议只在对应候选发布后可见。
- 共同测试支持连续测量系列、后续版本、锚题来源和题目版本知识点映射。
- 学校管理员可从 V1 准备 V2；页面明确提示真实作答仍是 V-E、IRT 和 BKT 的必要条件。
- 学校管理员模型页、共同题页和教师分层建议页已在 `375/768/1024/1440` 完成响应式验收。
- SQLite 与 PostgreSQL 均为 141 项测试通过；Redis/Celery 真实 worker 已领取一次夜间任务并生成两校测试候选。

上述模型和共同测试结果仍来自测试数据，只证明发布、回滚和采集程序可运行。

本次完成了模型训练前的四个必要阶段：

- `FEAT-01`：学习指标定义、计划分析时间点、多窗口特征快照、缺失原因和防未来信息混入。
- `OUTCOME-01`：未来结果成熟、无可用结果保留、匿名冻结数据版本、固定学生/时间分组和来源摘要。
- `LONG-01`：个人内变化、学生间差异、班级描述、重复测量相关结构和确定性范围。
- `MODEL-01 v2`：M00-M03 透明基线、V-A 至 V-E 检查方式、拒绝预测、可重复随机标签置换、防误判检查和模型卡。
- 学校管理员“分层分析”已改为可运行的“分析准备情况”页面，可建立时间点、更新到期结果、生成数据版本和导出 XLSX。
- 学校管理员页面可运行重复测量和基础方法比较，并导出模型卡、比较结果、重复测量和防误判检查；测试记录少于 30 条时性能字段保持为空。
- 夜间任务每天 02:50 冻结到时的计划点并更新到期结果。
- 新增专项测试覆盖防未来信息混入、缺失不补零、重复生成幂等、F4 隔离、角色权限和匿名导出。

此前完成的评价架构、共同测试和基础学习汇总继续有效：

- 旧 `ClassroomEvaluationConfig/Version` 停止产生新配置，旧 API 返回 `410`；可对应的历史提交已迁移到新冻结记录，其余保留兼容标记。
- “评价标准”只制定和发布，“课时设计”只绑定版本和评价方式，“课堂教学”只开启、执行和查看。
- 课堂首次开启评价冻结标准版本、三类开关、完整指标和内容哈希；自评、互评和师评分别保存并关联同课堂作答或作品。
- 题目标记普通题、共同题、分层题，分层题支持 A、B、C、A-B、B-C，且不能替代共同题。
- 学校管理员可按学科发布共同题集合；试卷保存题目版本、用途、适用范围和比较编号。
- 测试统计提供答对率、难度、区分度和选项分布；有效样本少于 30 时只显示“数据不足”。
- 已建立当日、近 7 日、近 30 日和单元学习情况，支持教师筛选、查看和 XLSX 导出。
- 透明规则建议只向任课教师显示；教师可采纳、保持、调整或暂缓，但不会直接修改学生层级。

此前完成的题目完整状态管理继续有效：

- 题库分为“我的题目”和“共享题库”；个人题目保存后教师本人即可组卷，不需要审核。
- 只有教师主动申请共享时，题目才进入待审核、可试用、已启用和已停用流程。
- 教师负责创建、修改、申请共享、撤回和复制个人题目；学校管理员只处理校内共享申请、试用、启用、退回和停用。
- 创建、XLSX 导入和 AI 确认均先保存到“我的题目”，不直接进入共享题库。
- 可试用题只对创建教师开放组卷；至少有 1 次真实学生作答后才能正式启用。
- 题目保存不可修改版本和完整状态记录，试卷保存来源版本与组卷时状态。
- 使用次数、作答人数和正确率从实际试卷、答卷计算，移除旧的累计计数字段。
- 新增学校管理员题库审核页面、详情弹窗和 XLSX 导出。
- 数据迁移保留原有 20 道启用共享题、20 个题目版本和 20 个试卷版本引用，并增加个人/校内共享范围字段。
- 评价、测试、共同题、学习汇总和权限均已补充专项回归测试。

当前小榄中学已有 4 条带“测试-”前缀的记录，可随时通过清理命令整批删除。
