## 4. 本轮发现并修复的问题

1. PostgreSQL 不允许对外连接可空侧直接使用无范围 `FOR UPDATE`；相关锁已限定为 `of=("self",)`，SQLite 无法发现此问题。
2. DEBUG 模式曾直接暴露 `/media/`，学生作品、资源和小组文件可绕过对象权限；现已改为受保护文件 API。
3. ONLYOFFICE 原来读取永久原始媒体地址；现改为带对象、版本和一小时时效的签名地址。
4. 学生响应过去依赖各业务序列化器自行隐藏字段；现增加 DRF 最终渲染出口和 WebSocket 发送出口的隐私阻断。
5. PostgreSQL 首轮文件测试失败源于测试调用 `response.close()` 关闭事务连接；修复测试资源清理后，定向 7 项及全量 88 项均通过。
6. 实库旧随机点名元数据曾包含 `picked_student.current_layer`，最终隐私闸门会阻止整个学生课堂响应；新写入已移除层级，学生 DTO 对历史元数据做受限字段清洗，最终闸门继续保留。
7. 通用后台壳层的隐式 Grid 列会被宽表格撑开，手机页面达到 830px；已改为 `minmax(0, 1fr)`，宽表只在自身容器滚动。
