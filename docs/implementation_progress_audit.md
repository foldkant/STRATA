# STRATA 当前开发进度

> 核对日期：2026-07-19  
> 核对依据：Git 提交、数据库迁移、自动化测试、Vue 构建和本机组件运行结果。

## 1. 总体结论

平台主要教学业务已经可以运行，学生学习记录和学校管理员学习数据检查也已经完成。当前正在完善评价与题目相关功能，还没有进入正式学生特征和机器学习模型开发。

不能把“页面已经存在”或“有模拟数据”理解为 AI 分层已经完成。目前没有可用于正式教学决策的模型结果。

## 2. 已经完成

### 平台基础

- Django、Vue 3、DRF、Channels 和 Celery 工程已经建立。
- 超级管理员、学校管理员、教师和学生主要页面已经接入 Vue。
- PostgreSQL、Redis、Channels 和 Celery 已完成本机验证。
- 学生端主要接口、WebSocket 和文件访问已经检查内部层级字段泄漏。

### 教学业务

- 学校、学校管理员、教师、学生、班级和任课关系管理。
- 学科前测、题库、测试、课程、课时设计和课堂教学。
- 资源、ONLYOFFICE、AI 学习网页、公告、反馈和学生档案。
- 签到、随机点名、抢答、倒计时、广播、小组合作、课堂评价和实名文字聊天。

### 学习记录

- 35 类受控学习事件。
- 学生实际获得的学习任务和任务状态。
- 客观题自动评分、主观题待评和教师复评版本。
- 课堂积分流水、冲正和余额核对。
- 新旧记录兼容写入、历史回填和记录核对。
- 学校管理员学习数据检查、XLSX 导出和夜间自动任务。

### 评价管理

- 评价方案和评价标准编辑。
- 评价指标、1-5 星表现说明和评分示例。
- 发布后保留不可修改的历史版本。
- 学校管理员维护，教师后续选用学校发布内容。

### 模拟数据

- 独立模拟学校和当前学校叠加测试两种模式。
- 固定随机种子，可重复生成同一批数据。
- 正式数据与模拟数据隔离。
- 支持整批清理。
