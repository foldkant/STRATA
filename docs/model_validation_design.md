# 统计验证与模型比较

> 版本：LONG-01 / MODEL-01 v2 / MODEL-02 v2 / MODEL-03 v3  
> 更新日期：2026-07-20

本模块用于验证学习数据、比较候选方法并生成教师审核建议。模型结果始终对学生隐藏；学校管理员查看汇总，任课教师只查看本人课程的个人建议。任何模型都不能自动修改学生层级。

## 1. 固定数据基础

每条分析记录对应“学生 × 学科 × 预先建立的分析时间点”。系统先冻结当时可用的学习指标，再等待随后 7 日结果成熟，最后生成不可修改的数据版本。

- 输入只使用 `operational_available` 快照，不读取时间点之后的信息。
- 指标键包含时间窗，例如 `opp_completion_rate__7d`。
- 缺失值保留原因，不用 0 代替。
- 正式数据和模拟批次不能混合。
- 少于 30 条测试记录时只显示“数据不足”，不报告性能结论。

## 2. LONG-01

LONG-01 在同一冻结版本内报告个人内变化、学生间差异、班级描述差异、重复测量相关结构和确定性范围。结果只描述关联，不使用因果措辞。

## 3. MODEL-01

| 编号 | 方法 | 用途 |
| --- | --- | --- |
| M00 | 总体平均 | 最低比较标准 |
| M01 | 透明规则 | 核查少量明确指标的方向 |
| M02 | 正则化统计 | 线性或逻辑统计基线 |
| M03 | 班级收缩 | 检查班级平均差异，不解释个人能力 |

所有方法使用相同验证范围：

- `V-A`：按时间留出。
- `V-B`：按学生整组留出。
- `V-C`：按班级整组留出。
- `V-D`：使用另一学校最新且同学科、同特征集、同结果定义的数据版本。
- `V-E`：测量或课程版本留出；没有第二个可比较版本时显示“暂不适用”。

## 4. MODEL-02

MODEL-02 在同一数据折比较 M00-M03、CatBoost 和 LightGBM。当前依赖固定为：

- CatBoost 1.2.10
- LightGBM 4.7.0
- scikit-learn 1.8.0
- NumPy 2.5.1
- pandas 3.0.3
- SciPy 1.18.0

每次运行保存：训练和测试数量、预测和拒绝数量、覆盖率、RMSE/MAE 或 Brier 分数、校准截距和斜率、特征重要性、重复训练稳定性及班级间误差差异。高级模型实际预测数未达到 30 时，MODEL-03 不启用。

`V-D` 每所外校只取最新兼容版本，避免把同一学校的历史版本重复计入测试集。跨校学科通过冻结清单中的标准学科键匹配；正式部署后需要由学校管理员维护学科标准映射。

## 5. 防误判检查

每次比较固定保存五项检查：

- 标签打乱后不应稳定优于总体平均。
- 随机匿名编号不应稳定优于总体平均。
- 输入名称不能包含未来结果字段。
- 离线、数据错误等审计字段不能进入首期主模型。
- 班级身份只用于差异检查，不解释为学生能力。

检查失败时结果标记为 `blocked`，不生成班级候选。

## 6. MODEL-03

MODEL-03 采用“全局结构化模型 + 班级残差收缩校准”，不为几十名学生从零训练独立树模型。

1. 从 MODEL-02 中选择可报告且主要指标较好的 CatBoost 或 LightGBM。
2. 使用完整冻结数据训练全局模型。
3. 计算班级残差，并向全局残差收缩，保存每班校准参数。
4. 保存模型文件路径和 SHA-256。
5. 为每名学生生成 A/B/C 教师审核候选。
6. 新候选生成后，旧的待处理模型候选标记为“已由新版替代”。

教师可采纳、保持、调整或暂缓；审核结果不直接改写 `StudentProfile.current_layer`。学生端不返回层级、置信度、模型原因或排名。

## 7. 夜间任务

每天 03:10 执行 `run_nightly_model_validation`：

1. 每个学校、学科、特征集和结果定义只取最新冻结版本。
2. 运行 LONG-01、MODEL-01、MODEL-02 和 MODEL-03。
3. 相同数据和代码版本直接复用已有结果。
4. 生成候选版本，等待教师确认。

Celery Beat 默认不传测试参数，因此正式任务自动排除模拟批次。开发验收可手动执行 `run_nightly_model_validation(include_test_data=True)`。

## 9. 候选发布与回滚

- 夜间任务只生成 `candidate`，教师在候选发布前看不到对应 MODEL-03 建议。
- 学校管理员发布时依次校验候选状态、比较运行、阻塞问题、教师确认规则、模型文件路径和 SHA-256。
- 发布生成包含清单、模型文件、公钥和 Ed25519 签名的离线 ZIP，并在切换当前版本前执行自校验。
- 同一学校、学科和测试数据范围只允许一个当前版本；正式数据与测试数据相互隔离。
- 发布失败不改变当前版本，成功和失败均写入不可修改审计。
- 回滚先重新校验历史模型包，成功后才切换当前版本；历史发布记录不删除。

专项回归已在 SQLite 和 PostgreSQL 各验证发布、篡改拒绝、失败保护、新版本替换、旧版本回滚、跨校权限和教师可见性。运维流程见[模型发布、校验与回滚](model_release_operations.md)。
