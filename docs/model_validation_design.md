# 统计验证与模型比较

> 版本：MODEL-01 v2 · 更新日期：2026-07-20

这部分用于检查数据是否适合进入后续模型研究，不是自动给学生分层，也不是给教师发布教学建议。学校管理员可以查看汇总结果，学生和教师不能看到个人预测、匿名编号或模型输入。

## 1. 两个里程碑

### LONG-01：重复测量统计

同一冻结数据版本中的一名学生可能在多个分析时间点出现。系统分别计算：

- **个人内变化**：同一名学生不同时间点的变化。
- **学生间差异**：不同学生长期平均水平的差异。
- **班级差异**：班级均值的描述性差异，不把班级身份当作学生能力。
- **重复测量相关结构**：总差异、学生间差异、个人内差异和 ICC 描述值。
- **方向范围**：按学生匿名编号做确定性聚类重采样，给出相关方向的近似 95% 范围。

结果只使用冻结的 `operational_available` 数据和已观察结果。输出使用“正向关联、负向关联、无明显关联、数据不足”，不使用“导致”“证明有效”等因果措辞。有效观测少于 30、学生少于 10 或班级少于 2 时，只显示“数据不足”。

### MODEL-01：透明基线与验证折

四个基线在同一份冻结数据、同一结果定义和同一验证折上运行：

| 编号 | 名称 | 用途 |
| --- | --- | --- |
| M00 | 总体平均基线 | 最低比较标准，不读取行为指标 |
| M01 | 透明规则基线 | 使用少量明确指标，供教师理解和方向核查 |
| M02 | 正则化统计基线 | 当前离线环境下的可重复线性/逻辑统计实现；正式 Elastic Net 依赖接入前只作工程基线 |
| M03 | 班级收缩基线 | 在总体平均基础上做班级均值的有限收缩，不从小班级从零训练复杂模型 |

验证折：

- `V-A`：按分析日期从早到晚做时间外推。
- `V-B`：按学生匿名编号整组留出，避免同一学生同时出现在训练和测试。
- `V-C`：按班级整组留出，检查新班级情境。
- `V-D`：单校数据不伪造跨校测试，标记为暂不适用；跨校分析必须导入独立学校数据版本。
- `V-E`：当前数据只有一套测量定义时标记为暂不适用；课程或测量版本变化后再建立外推折。

测试记录少于 30 条时不报告正式指标，只保留数据不足状态。每条模型预测保存 `predicted` 或 `abstained` 状态；没有足够输入指标时拒绝预测，不用 0 代替。标签打乱检查使用由数据版本确定的可重复随机置换，不沿用记录顺序倒排。

## 2. 模型卡

每次比较固定保存：

- 数据版本、特征集版本、结果定义版本和来源摘要。
- 目标类型、模型清单、验证折、训练/测试记录数。
- 缺失处理、拒绝预测规则、覆盖率和评价指标。
- 负对照结果、限制条件和适用范围。
- 数据是正式数据还是模拟数据。

当前比较状态最多为“影子比较”。它不能直接改变学生层级，不能公开个人预测，不能替代教师判断，也不能证明动态分层改善了学习效果。

## 3. 负对照

每次比较保存以下检查：

- **标签打乱**：标签被打乱后不应稳定优于总体平均基线。
- **随机匿名编号**：随机匿名编号不应稳定优于总体平均基线。
- **未来哨兵**：输入指标名称不能包含分析时间点之后的结果字段。
- **数据可用性**：离线、数据错误等技术条件不能进入首期主模型输入。
- **班级身份**：保留班级基线供检查，但不将班级身份解释为学生能力。

负对照失败时，模型比较状态为“暂不输出”，不会继续产生教学建议。

## 4. 夜间任务

每天 03:10 执行 `run_nightly_model_validation`：

1. 查找已冻结的正式数据版本。
2. 建立 LONG-01 重复测量统计。
3. 建立 MODEL-01 M00-M03 比较。
4. 任一版本已存在时直接复用，避免重复记录。
5. 保存“影子比较”或“暂不输出”状态，不做部分发布。

模拟数据不进入正式夜间任务；模拟批次只能用于验证程序、页面、导出和异常处理。

## 5. 下一步边界

只有当真实学校数据达到预先规定的样本量，并完成时间外推、班级外推、校准、拒绝预测、公平检查和教师任务模拟后，才考虑 MODEL-02 的 CatBoost、LightGBM 或 IRT/BKT 比较。即使后续通过，也只能生成教师审核建议，不能自动修改学生层级。
