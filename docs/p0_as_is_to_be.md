## 1. 为什么单独建立本基线

`evaluation_stratification_grouping_sci_design_rounds_11_30.md` 保存的是重构决策形成时的科学设计记录。其中关于课程标准“尚无运行时模型和接口”的描述属于实施前历史状态，不能继续作为当前工程状态。本文只描述 2026-07-22 的实际代码和开发库，不改写原科学论证的形成过程。

本轮先在课程标准专用后台任务的安全停写边界完成最终备份和迁移，再恢复 Web 与单并发低优先级 worker。`curriculum_standards.0004` 和 `learning_analytics.0032` 已在隔离恢复副本及开发库验证并应用；本文件记录迁移后的 P0—P1 状态。

## 3. 目标状态（TO-BE）

### 3.1 P0 收口后的目标状态

1. 术语、角色权限、版本不可变规则和数据用途形成带编号的工程冻结清单。
2. 当前代码、治理文档、数据库备份和课程标准媒体目录形成可核验的 SHA-256 基线。
3. 历史/手工测试数据只能由超级管理员按精确模型和主键登记；不得按标题模糊批量标记。
4. 每次迁移保存源对象、目标对象、数量、批次、校验结果、异常和回滚位置。
5. 数据库、媒体和代码回滚具有停服条件、恢复步骤、校验命令和失败停止条件。

### 3.2 P1 收口后的目标状态

1. 超级管理员能够管理 K1—K9、K10—K12 的课程标准档案和历史版本。
2. 每个版本保存原 PDF、来源、正式题名、发布日期、适用范围、文件 SHA-256、解析器版本和操作记录。
3. 逐页文本、结构化内容条目和 AI 检索片段都能返回具体版本、页码和原文；旧版本不被覆盖。
4. 解析、逐页复核、版本复核、发布、替换、比较、归档和恢复分别留痕并执行职责分离。
5. 只有已发布且完成规定复核的版本可以被后续正式评价方案引用。

### 3.3 P2 以后目标状态，不得提前冒充已完成

| 后续能力 | 目标对象或行为 | P0—P1 当前禁止声称 |
| --- | --- | --- |
| 评价重构 | 课标约束的学习目标、评价依据、多种评价任务、评分规则、个人/小组评价材料和用途准入 | 不能把课标句子直接当评分项，不能把测试当作全部评价 |
| 目标级学习状态 | 多来源合格评价材料、质量和可比性判断、区间与不确定性、追加式状态版本 | 不能把一次评价结果或前测分数直接称为稳定能力 |
| 动态内容安排 | 内容带政策读取用途合格的状态，在合法时点产生可拒绝建议，由教师确认 | 不能自动降低学习内容层级，不能把缺失记为最低层级 |
| 任务条件化分组 | 任务、目标、成员条件、安全与机会约束产生候选，教师确认并记录实际实施 | 不能复制 A/B/C 成组，不能把计划机会写成实际教育效果 |
| AI 辅助评价 | 仅检索适用课标原文和去身份教学情境，生成可编辑初稿，保存模型、提示、检索和修改差异 | 不能自动发布、自动评分、自动分层或自动分组 |
| 教育实验 | 前测一致、干预与对照边界冻结、后测/问卷版本化、预注册统计计划与伦理治理 | 工程测试或模拟数据不能成为 SCI/SSCI 效果结论 |

## 5. 变更控制

本基线之后，任何涉及统一名称、角色权限、发布条件、版本覆盖、测试数据范围或数据用途的变化，都必须：

1. 新建基线版本，不覆盖本文；
2. 记录提出原因、影响对象、迁移和回滚方法；
3. 更新 `terminology.md`、权限测试、迁移台账和基线 manifest；
4. 在隔离数据库通过迁移、回滚和权限测试后，再选择后台任务安全边界应用到开发库；
5. 涉及真实学生、正式统计或研究用途时，另行取得学校、数据治理、伦理和研究责任人的批准。
