# 学习分析页面多分辨率验收

> 验收日期：2026-07-20  
> 验收环境：Chrome Headless、Django ASGI、SQLite 开发库、本地 Vue 生产构建

## 验收范围

| 角色 | 页面 | 375 | 768 | 1024 | 1440 |
| --- | --- | --- | --- | --- | --- |
| 学校管理员 | `/app/school-admin/models` | 通过 | 通过 | 通过 | 通过 |
| 学校管理员 | `/app/school-admin/question-reviews` | 通过 | 通过 | 通过 | 通过 |
| 学校管理员 | 共同题集合弹窗 | 通过 | 通过 | 通过 | 通过 |
| 教师 | `/app/teacher/stratification` | 通过 | 通过 | 通过 | 通过 |

检查内容包括横向溢出、文字截断、按钮换行、移动端点击区域、表格宽度、弹窗高度、内容滚动和浏览器运行时错误。

## 本轮修复

- 修复前端已更新而无热重载后端仍返回旧字段时，模型页面因缺少发布列表而空白的问题。前端现在对旧响应中的可选列表使用空数组降级。
- 教师学习情况和分层建议表在 `768/1024` 提前切换为卡片布局，不再依赖横向滚动查看右侧字段。
- 学校题库审核表在中等宽度切换为卡片布局。
- 共同题集合弹窗改为固定头部和底部操作栏，中间题目区域独立滚动。
- 移动端主要操作、筛选和弹窗控件的点击高度统一到至少 `44px`。

## 验收结果

- 四档宽度均未发现页面级或可见内容横向溢出。
- 登录后目标页面无 JavaScript 运行时错误。
- 登录页初始化时 `/api/v1/auth/me/` 返回一次 `403` 属于未登录状态探测，登录成功后对应接口返回 `200`，不计为页面故障。
- 临时截图和自动化脚本仅用于本轮验收，审查完成后删除，不提交仓库。

## 剩余风险

- 模拟数据产生较多历史模型运行，学校管理员页面会较长；正式试用前应按学校保留策略清理测试批次。
- ECharts 分包仍超过 Vite 默认的 `500 kB` 提示线，属于后续首屏性能优化，不影响本轮布局验收。
- 正式学校仍需用实际教师账号、真实班级数量和学校常用显示器再执行一次同表验收。
