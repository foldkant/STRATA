# 校级科研数据分析规划

> 状态：后续开发，不属于当前分层模型训练页面。

## 1. 定位

面向学校管理员和经授权的研究人员，提供本校匿名研究数据整理、统计分析、图表和结果导出。该模块与日常教学分层分开：分层页面负责模型训练和发布，科研分析页面负责预先登记后的研究统计。

## 2. 首期分析范围

- 描述统计：人数、均值、标准差、中位数、四分位数、分布和缺失情况。
- 量表检查：项目分析、Cronbach's alpha、项目与总分相关；因子分析必须满足样本条件后才开放。
- 两组比较：独立样本或配对 t 检验，并提供非参数替代方法。
- 多组比较：单因素和重复测量方差分析，报告效应量和多重比较处理。
- 相关与回归：Pearson/Spearman、线性回归和必要的协变量控制。
- 纵向分析：时间点变化、班级聚类和混合效应模型作为后续研究能力。

## 3. 输出要求

- 所有结果同时显示样本量、缺失数量、效应量、置信区间和必要的假设检查，不能只显示 `p` 值。
- ECharts 用于学校端交互查看；论文正式图应从匿名数据和分析脚本在 Python/R 中重复生成。
- 支持 XLSX、CSV、PNG 和分析参数清单导出，保留软件版本、变量定义和运行时间。
- 不直接输出可识别学生的跨班级排名。

## 4. 与 SPSS 的关系

第一版优先提供常用、可复现的统计流程，并允许导出 SPSS 可读取的 XLSX/CSV 及变量字典。后续如需 `.sav` 文件，可评估离线集成 `pyreadstat`。平台不能仅模仿 SPSS 按钮，还必须保存分析参数、样本筛选和代码版本，保证论文结果可以复核。

## 5. 开发前置条件

- 完成研究变量字典和量表版本冻结。
- 完成伦理审批、未成年人同意和研究预注册。
- 明确学校管理员与研究人员的数据权限边界。
- 使用真实纵向数据验证统计口径；模拟数据仅用于工程测试。
