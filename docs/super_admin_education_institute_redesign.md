# 超级管理员端“教育研究院”视觉与交互重构

日期：2026-07-24

## 设计定位

超级管理员端采用“教育研究院”方向。界面面向平台治理人员，强调课程标准、学校运行、数据治理与系统运维的可信表达。

设计参数：

- 视觉变化：5/10。保持后台工具的稳定结构，同时通过字体、配色和不对称信息布局形成识别度。
- 动效：2/10。只保留悬停、按压和导航展开反馈。
- 信息密度：7/10。首页保留完整治理数据，但先呈现待处理事项，再呈现规模与趋势。

## 语义令牌

| 用途 | 色值 |
| --- | --- |
| 主色，黛青 | `#183D37` |
| 深色文字 | `#102F2A` |
| 页面底色，雾白 | `#EDF1ED` |
| 内容纸色 | `#F7F8F4` |
| 强调色，朱砂 | `#B54A3A` |
| 分隔线 | `#D7DED8` |

标题使用本机宋体系列，正文使用本机中文无衬线字体。两套字体都通过 `local` 字体栈调用，不产生网络请求。

## 信息架构调整

- “平台待办”改为一级入口“平台总览”。
- 学校与账号：学校管理、学校管理员。
- 标准与资源：课程标准。
- 数据治理：数据采集、跨校分析。
- 平台运维：系统运行。
- 首页先显示治理关注事项和常用治理入口，再显示平台规模、构成、趋势、学校规模和操作记录。
- “跨校数据采集”在导航中缩写为“数据采集”，页面内仍说明其跨校治理范围。
- “系统健康”在导航中改为“系统运行”，页面内部保留“系统健康”作为具体检查任务名称。

## 私有化资源

- 图标：`@tabler/icons-vue`，通过 npm 安装并打包进本地 Vite 产物。
- 图表：项目原有 `echarts` 本地依赖，不加载 CDN。
- 字体：本机中文字体栈，不请求 Google Fonts 或其他在线字体。
- 图片：超级管理员端没有引入远程装饰图片。
- 样式：`src/styles/super-admin-theme.css` 作为超级管理员路由的独立本地样式包按需加载。

浏览器验收记录显示，超级管理员 7 个页面的运行时请求来源只有 `http://127.0.0.1:8010`。
