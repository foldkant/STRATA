# 教师试用培训指南

## 培训目标

教师完成培训后应能独立完成课程准备、评价标准发布、共同测试实施、学习情况查看和隐性分层建议审核，并能说明模型不能替代教师决定。

## 建议安排

### 模块 1：教学流程

- 建立课程、课时和学习环节。
- 加入资源、课堂题、附件任务和 AI 学习网页。
- 开启课堂、查看作答、结束课堂和处理异常提交。
- 明确课时设计、课堂执行和课程资源中心的边界。

### 模块 2：评价与测试

- 制定评价方案、评价标准和 1-5 星指标。
- 在课时选择已发布标准，课堂开启时冻结版本。
- 正确使用“暂不评价”，材料缺失不能自动给低星。
- 区分“我的题目”和“共享题库”；个人题无需审核，申请共享后由学校审核。
- 共同题不能被 A/B/C 分层题替代，已完成答卷始终绑定当时题目版本。

### 模块 3：学习情况与建议

- 解释当日、近 7 日、近 30 日和单元汇总。
- 区分“没有任务”“尚未完成”“请假/离线”“记录错误”和真实低完成。
- 审核建议时查看材料、原因和适用范围，选择接受、保持、调整或延后。
- 不向学生展示或口头公布 A/B/C、概率、排名和模型理由。
- 发现不合理建议时记录原因，不为了完成待办机械接受。

## 必做演练

1. 建立一个测试课时并完成教师/学生双端流程。
2. 发布评价标准，完成一次自评或教师评价，验证历史版本不随工作稿变化。
3. 创建包含共同题和普通题的测试并完成一份答卷。
4. 识别一条“材料不足”记录并说明为什么不能按 0 分处理。
5. 审核一条测试候选建议并填写处理说明。
6. 模拟网络中断、学生错班和文件提交失败，按流程恢复。

## 通过标准

- 能正确完成全部必做演练。
- 能说出学生端不可见的内部字段。
- 能区分工程测试结果与正式研究结论。
- 能找到学校数据保护联系人和故障报告入口。
- 未通过者只使用普通教学功能，不进入分层建议试用。

## 培训记录

保存培训日期、版本、讲师、教师名单、完成情况、常见问题和补训记录。平台版本或评价/建议流程发生实质变化后，需要补充培训并更新材料版本。
