## 面向一线教师的界面判断

本轮采用“少做选择、先给可修改初稿、关键节点由教师确认”的原则：

1. AI 可见流程由 7 个技术步骤归并为 4 个教师任务：确认教学信息、核对课标依据、生成并审阅初稿、保存草案。
2. 课程、学段、年级、单元、课时内容和唯一匹配课标尽量自动带入。
3. 评价方式建议和教师确认放在同一屏，可一键进入生成；保留“分步确认”供需要详细控制的教师使用。
4. 手工流程提供完整的可修改结构，不再要求教师理解数据关系后从空白搭建。
5. AI 不能直接发布、进入课堂、评分、分层或分组；自动检查未通过时不能靠批量采纳绕过。

仍需继续优化的重点是审阅负担：一份完整 AI 初稿可能包含 30—40 余项审阅记录。当前批量采纳已能快速完成操作，但更适合一线教师的下一版应默认展示“方案摘要、关键风险和待教师决定项”，其余对应关系按需展开。
