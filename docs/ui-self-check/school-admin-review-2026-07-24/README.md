# 校管理员端前端重构与自检

## 本轮范围

校管理员工作空间已经接入与超级管理员一致的“教育研究院”视觉体系，并根据学校日常教学管理重新组织信息层级。全部图标、图表和样式资源均随前端项目本地构建，不依赖外部字体、图标或图片服务。

本轮覆盖以下页面：

- 首页
- 班级管理
- 教师管理
- 学生管理
- 任课关系
- 学习起点诊断
- 资源审核
- 题库审核
- 数据检查
- 学习情况与支持建议

教育实验页面仅接入新的公共导航与视觉外壳，没有沿用或继续扩展原有业务方案；该功能仍按既定计划单独重构。

## 主要调整

- “首页”改为独立一级入口，不再放入“当前任务”二级分组。
- 导航按“教学组织、诊断与评价、学习支持、教育研究”组织，并统一使用本地 Tabler 线性图标。
- 首页先呈现需要处理的事项和常用工作，再呈现学校基本情况、近期学习情况、班级与任课、学生与账号、诊断与学习情况分析。
- 手机端首页图表采用分区横向浏览，避免形成过长的单列图表页面。
- 管理表格在手机端转为带字段名称的记录卡片；桌面端保留紧凑表格和清晰的行内操作。
- 统一表单、筛选区、状态提示、弹窗、页签、图表和焦点样式；补齐通过 `Teleport` 打开的弹窗主题。
- 将教师、学生和任课关系页面中的系统内部表达改为学校教学管理语境。
- 学习起点诊断、数据检查和学习情况分析图表改用深绿、朱砂和暖灰配色。
