- 教师端与学生端共 28 个路由状态。

## 第一轮：布局基线

- 教师工作台在 768px 下改为抽屉导航，不再保留 248px 固定侧栏。
- 学生端增加折叠导航，平板宽度下品牌、导航和账号操作保持紧凑。
- 学生课堂在 900px 以下由强制双栏改为上下布局，资源区保留稳定高度，任务区使用页面滚动。
- 公共按钮、链接和表单控件增加统一 `focus-visible` 状态。
- 表格继续使用容器内横向滚动，不允许撑宽页面。

## 第二轮：组件与响应式

- 新增 `useRouteMenu`，教师与学生 Shell 共用导航开合和路由切换关闭逻辑。
- 课时设计顶部操作在平板宽度下改为自适应网格，避免单按钮占一行。
- 教师课堂顶部操作在平板宽度下保持紧凑排列，手机宽度下降级为两列。
- 复核现有 `ManagementPage`、`NoticeLine`、`MultiSelectActions`、`ClassChipList` 等组件，继续作为列表、提示、批量选择和班级摘要的统一实现。

## 第三轮：前后端结构

- Vue 路由全部改为动态导入，登录页保留同步加载。
- 初始 JavaScript 从约 1269 KB 降至约 119 KB；课时设计、课堂控制、ECharts 和各角色页面按需加载。
- 课时评价、AI 学习网页工作室、题目统计图和学习网页统计弹窗改为异步组件。
- 后端新增 `api/view_utils.py`，统一分页、当前学校上下文和服务错误响应转换。
- Django `check` 通过，20 个 API 测试全部通过。

## 第四轮：交互与可访问性

- 教师与学生 Shell 增加“跳到主要内容”键盘入口。
- 响应式抽屉和跳转入口支持 `prefers-reduced-motion`。
- 为资源搜索、题库筛选、测试状态、课程搜索和公告搜索补齐可访问名称。
- 题库新增题目弹窗改为固定头部和底部、正文独立滚动；12 个弹窗状态的底部操作均可见。
- 最终页面扫描未发现页面级横向溢出或 Vue 运行时异常。

## 后续规则

- 新页面必须在 1440、1280、768 三种宽度下检查；学生核心学习页另加 375px 检查。
- 页面不得依赖固定高度承载可增长列表；表格、编辑器和弹窗正文可以拥有明确的局部滚动区。
- 共享交互优先扩展现有组件或 composable，禁止在页面内复制批量选择、提示、分页和导航状态逻辑。
- 新增文件上传必须复用 `FilePicker`；即时上传和随表单保存可以保留不同业务时机，但外观、状态反馈和可访问性规则必须一致。
- 新增重型页面、图表或编辑器必须使用路由或组件级动态导入。
- 临时截图只用于审查，确认后删除，不提交到仓库。
